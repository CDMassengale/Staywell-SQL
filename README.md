# StayWell Property Management Database

## Description
The StayWell Property Management Database is a relational database designed to organize and manage information for a property management company. 
The database stores information about property owners, offices, properties, residents, and maintenance service requests.

## Tools and Languages
- **MySQL:** Used to create, manage, and query the relational database.
- **MySQL Workbench:** Development environment used to write and execute SQL scripts.
- **SQL:** Used to create tables, define relationships, and insert records.

## Database Tables
The database consists of six main tables:
- **OWNER:** Stores property owner information, including names and addresses.
- **OFFICE:** Stores information about property management office locations.
- **PROPERTY:** Stores property details, including square footage, bedrooms, rent, and ownership.
- **SERVICE_CATEGORY:** Stores categories of maintenance services.
- **SERVICE_REQUEST:** Tracks maintenance requests, descriptions, status, estimated hours, and hours spent.
- **RESIDENTS:** Stores resident information and associates residents with properties.

## Features
- **Table Creation:** Created six relational database tables using SQL.
- **Primary Keys:** Established unique identifiers for database records.
- **Foreign Keys:** Created relationships between tables to maintain referential integrity.
- **Data Insertion:** Populated tables with sample property management data.
- **Relational Database Design:** Connected owners, offices, properties, residents, and maintenance requests.
- **Data Organization:** Structured information into separate tables to reduce unnecessary duplication and improve organization.

## What I Built
I designed and implemented a relational database for a property management company called StayWell. 
Using SQL in MySQL Workbench, I created six tables, established primary and foreign key relationships, and inserted sample records into each table. 
The database provides an organized structure for managing property information, residents, owners, and maintenance requests.
